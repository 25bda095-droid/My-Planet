# Quick Notes

## Sorting Complexity

| Algorithm | Time Complexity |
|----------|----------------|
| Bubble Sort | O(n²) |
| Selection Sort | O(n²) |
| Insertion Sort | O(n²) |
| Merge Sort | O(n log n) |
| Quick Sort | O(n log n) |
| Heap Sort | O(n log n) |

## complexity of Linkedlists
| Operation        | Time Complexity |
| ---------------- | --------------- |
| Insert Beginning | O(1)            |
| Insert End       | O(n)            |
| Insert Position  | O(n)            |
| Delete Beginning | O(1)            |
| Delete End       | O(n)            |
| Search           | O(n)            |
| Traverse         | O(n)            |

## complexity of Double linked lists

| Search           | O(n)            |
