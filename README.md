# 🐧 Learn WSL (Windows Subsystem for Linux)

### ⚙️ Installation


Enable:

Windows Subsystem for Linux

Virtual Machine Platform

Run:
wsl --install

Restart system


---

### 🛠️ Useful Commands


wsl --update
wsl --version
wsl --list
wsl --set-default <Distro>


---

### 🖥️ GUI Setup


sudo apt update && sudo apt upgrade
sudo apt install kali-win-kex

# 🐞 Bug Bounty Methodology

## ⚡ Strategy
- Chain vulnerabilities 🔗  
- Analyze every request via proxy 🔍  
- Focus on logic flaws 🧠  

---

## 🎯 Vulnerabilities

### 🔸 XSS
- Test all inputs  
- Use payload variations  

### 🔸 CSRF
- Remove/modify token  
- Change request type  

### 🔸 IDOR
- Modify IDs  
- Use 2 accounts  

### 🔸 SSRF
- Access internal endpoints  

### 🔸 Open Redirect
- Abuse redirect parameters  

### 🔸 Account Takeover
- Weak reset logic  
- OTP bypass  

### 🔸 File Upload
- Change file types  
- Inject payloads
